# 代码规范

## 文件编码

- 所有文件必须使用 **UTF-8 编码**保存，禁止使用 GBK、GB2312、Latin-1 等其他编码
- 避免用 PowerShell 处理含中文的文件
- 创建或修改文件时，始终通过工具写入（fsWrite / strReplace），不要用系统文本编辑器另存为
- 写入 HTML / Python / JSON 等文件后，如有中文内容，用以下命令验证编码：
  ```bash
  python -c "open('path/to/file', encoding='utf-8').read(); print('OK')"
  ```
- 若发现文件含有损坏字节（`\ufffd` 替换符），立即用 Python 脚本修复并重新以 UTF-8 保存，不要忽略

## PowerShell / JSON 操作注意事项

- PowerShell 的 `ConvertTo-Json` 会输出非标准缩进格式，且 `Set-Content -Encoding UTF8` 会写入 UTF-8 BOM（`\xEF\xBB\xBF`），导致后续 Python `json.load()` 报错 `Unexpected UTF-8 BOM`
- 因此，修改 JSON 文件时优先使用 Python 而非 PowerShell：
  ```bash
  python -c "
  import json
  path = 'path/to/file.json'
  with open(path, 'r', encoding='utf-8-sig') as f:
      data = json.load(f)
  # ... 修改 data ...
  with open(path, 'w', encoding='utf-8') as f:
      json.dump(data, f, indent=2, ensure_ascii=False)
  "
  ```
- 如果已经被 PowerShell 写入了 BOM，读取时用 `encoding='utf-8-sig'` 兼容，写回时用 `encoding='utf-8'`（无 BOM）
- 对于用户主目录下的文件（如 `~/.kiro/settings/mcp.json`），`strReplace` / `fsWrite` 工具可能无法直接访问，需要通过 `executePwsh` 调用 Python 脚本来操作
